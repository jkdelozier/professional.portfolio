# professional.portfolio

A minimal, professional portfolio website starter for JDeLozier.

## What's Included

- `index.html` — semantic, accessible portfolio page with sections for:
  - Experience
  - Projects
  - Skills
  - Contact
- `styles.css` — lightweight responsive styling for a clean professional layout.

## Local Preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Customize

Update the placeholder content in `index.html`:

- Name and professional summary
- Experience and project details
- Skills list
- Contact email and LinkedIn URL

This repository is intentionally simple so it can grow with additional pages,
assets, and tooling as needed.
